# Swift OMS Sentry
Add On Module for Exam OMS

## Add Repo
```
composer config repositories.haryo-exam git git@github.com:agustinusharyokp/exam-oms-haryo-01.git
```

## Install
```
composer require icube-mage/exam-oms-haryo-01:dev-oms-exam
```

## Update Repo
```
composer update icube-mage/exam-oms-haryo-01
```
